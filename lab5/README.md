# Лабораторная работа №5 — оркестратор Single-SPA

Оркестратор показывает меню и подключает две предыдущие лабораторные как микрофронтенды. Обе ленты обращаются к [JSONPlaceholder](https://jsonplaceholder.typicode.com/) через Axios.

| Маршрут | Что открывается |
| --- | --- |
| `/` | Главная страница с выбором приложения |
| `/react` | Лента на React из лабораторной №3 |
| `/vue` | Лента на Vue из лабораторной №4 |

## Запуск в Windows

Нужны Node.js 20.19+ в ветке 20 или 22.12+ и интернет. Откройте папку `lab5` в Проводнике, введите `powershell` в адресной строке и нажмите Enter. Выполните команды по очереди.

```powershell
npm.cmd ci
npm.cmd run dev
```

Откройте адрес из строки `Local`. Обычно это `http://127.0.0.1:5173/`. Если порт занят, Vite покажет другой адрес. Оставьте окно PowerShell открытым, пока пользуетесь приложением.

Для проверки сборки выполните `npm.cmd run build`, затем `npm.cmd run preview`. При размещении `dist/` на сервере он должен отдавать `index.html` для `/react` и `/vue`, чтобы прямые ссылки и обновление страниц работали. Сборка рассчитана на корень сайта.

## Как подключаются микрофронтенды

1. `src/orchestrator/main.js` регистрирует приложения через `registerApplication`. Функция `activeWhen` связывает каждое приложение с его маршрутом.
2. При переходе через меню `navigateToUrl` меняет адрес без перезагрузки. Single-SPA подгружает нужную точку входа через динамический `import()`.
3. `single-spa-react` и `single-spa-vue` предоставляют `bootstrap`, `mount` и `unmount`. Оркестратор передаёт каждой реализации свой контейнер через `customProps`.
4. Vite собирает проект одной командой. React и Vue загружаются отдельными модулями при первом переходе на соответствующий маршрут. CSS каждого приложения ограничен его контейнером.

Состояние ленты сбрасывается при уходе с маршрута, поскольку Single-SPA размонтирует приложение. JSONPlaceholder имитирует публикацию и удаление, поэтому на сервере изменения не хранятся.

## Структура

```text
lab5/
├── index.html                         # меню и контейнеры
├── package.json
├── package-lock.json
├── vite.config.js                     # плагины React, Vue и префиксы CSS
└── src/
    ├── orchestrator/
    │   ├── main.js                    # регистрация и навигация
    │   └── style.css
    └── microfrontends/
        ├── react/                     # страницы, компоненты, hooks, API
        │   └── entry.jsx              # жизненный цикл React приложения
        └── vue/                       # страницы, компоненты, composables, API
            └── entry.js               # жизненный цикл Vue приложения
```

## Проверка

1. Нажмите «React» в меню и убедитесь, что открылась лента на `/react`.
2. Нажмите «Vue». Меню должно остаться на экране, а лента смениться без перезагрузки.
3. Проверьте кнопки «Назад» и «Вперёд» в браузере, а также прямое открытие и обновление обоих маршрутов.
4. В каждой ленте найдите пост, опубликуйте тестовую запись и удалите её.

Для GitHub добавляйте папку `lab5`. В архив включены исходники и lock-файл. Папки `node_modules/` и `dist/` создаются локально.

# Лабораторная работа № 2 — «Заметки»

Простое веб-приложение на **HTML5, CSS3 и JavaScript с Ajax**.
Источник данных: [JSONPlaceholder](https://jsonplaceholder.typicode.com/).
Сделано по функциональному образцу предоставленных проектов: список постов,
форма добавления, удаление и обновление списка. Дополнительно есть поиск.

## Запуск

Откройте `index.html` в современном браузере. Для запросов нужен интернет.
Установка зависимостей, сборка и собственный сервер API не требуются.

Если браузер ограничивает запросы со страницы `file://`, откройте терминал
**в папке `lab2`** и выполните:

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

Затем перейдите на [http://127.0.0.1:8080](http://127.0.0.1:8080).
Остановка сервера: `Ctrl+C`. Также подойдёт Live Server в VS Code.

## Возможности

- Автоматическая загрузка 12 постов при открытии страницы.
- Создание поста: обязательные заголовок и текст, автор № 1.
- Удаление выбранного поста после успешного ответа API.
- Обновление исходного списка кнопкой «Обновить».
- Поиск без учёта регистра по заголовку и тексту загруженных постов.
- Состояния загрузки, пустого списка, успешных операций и ошибок.
- Проверка ввода: нельзя отправить одни пробелы; заголовок до 150 символов,
  текст до 2000 символов. При ошибке отправки введённый текст сохраняется.
- Адаптивная вёрстка, подписи полей, управление клавиатурой и сообщения
  для программ чтения с экрана.

## Ajax-запросы

Базовый адрес: `https://jsonplaceholder.typicode.com`.
В `app.js` функция `ajax()` использует асинхронный `XMLHttpRequest` и возвращает
`Promise`. Данные отправляются в JSON с заголовком `Content-Type`.
HTTP-статус проверяется, ошибки сети и тайм-аут 15 секунд обрабатываются.

| Действие | Метод | Путь |
| --- | --- | --- |
| Загрузить список | GET | `/posts?_limit=12` |
| Создать пост | POST | `/posts` |
| Удалить пост | DELETE | `/posts/{id}` |

Тело запроса создания:

```json
{
  "title": "Моя первая заметка",
  "body": "Текст заметки",
  "userId": 1
}
```

Поиск выполняется в браузере по текущему списку, без дополнительных запросов.
При публикации поиск сбрасывается, чтобы новая заметка была видна.
Данные API и пользователя выводятся через `textContent`, чтобы текст с HTML
не превращался в разметку или исполняемый код.

## Особенность учебного API

JSONPlaceholder имитирует создание и удаление: изменения **не сохраняются
на сервере**. Поэтому обновление страницы или успешное обновление списка
возвращает исходные данные. Это поведение описано в
[официальной документации](https://jsonplaceholder.typicode.com/).

При нескольких POST сервер возвращает одинаковый `id: 101`. Приложение
дополнительно присваивает карточкам разные локальные ключи: удаление одной
новой заметки не удаляет остальные. Изменения хранятся только в памяти страницы.

## Как проверить работу

1. Откройте страницу: должны появиться 12 постов.
2. Введите слово из заголовка в поиск: список отфильтруется.
3. Очистите поиск или нажмите «Сбросить поиск» при отсутствии результатов.
4. Заполните форму: новая заметка появится первой, форма очистится.
5. Создайте ещё одну заметку и удалите одну из новых: вторая останется.
6. Нажмите «Обновить»: появятся исходные 12 постов.
7. В DevTools → Network отфильтруйте Fetch/XHR: видны GET, POST и DELETE.
8. Отключите сеть в DevTools и обновите список: появится ошибка с кнопкой
   повтора, а ранее загруженные карточки останутся на экране.

## Что объяснить при защите

- HTML5 задаёт семантическую структуру (`header`, `main`, `section`, `article`,
  `form`, `footer`).
- CSS3 оформляет элементы; Grid и медиазапросы адаптируют колонки к экрану.
- JavaScript обрабатывает события и меняет DOM без перезагрузки страницы.
- Ajax выполняет асинхронные HTTP-запросы через `XMLHttpRequest`.
- JSON — формат обмена данными; `JSON.stringify` формирует запрос,
  `JSON.parse` разбирает ответ сервера.

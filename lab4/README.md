# Лабораторная работа №4 — «Лента постов» на Vue

Простое приложение на Vue 3. Лента получает данные из [JSONPlaceholder](https://jsonplaceholder.typicode.com/) через Axios. В ней можно искать посты по заголовку и тексту, фильтровать по автору, переключать страницы, публиковать и удалять записи.

JSONPlaceholder имитирует публикацию и удаление. Изменения видны до перезагрузки страницы. Для публикации используется тестовый пользователь №1.

## Запуск в Windows

Нужны Node.js 20.19+ в ветке 20 или 22.12+ и интернет. Откройте папку `lab4` в Проводнике, введите `powershell` в адресной строке и нажмите Enter. В открывшемся PowerShell выполните команды по очереди.

```powershell
npm.cmd ci
npm.cmd run dev
```

Откройте адрес из строки `Local`, обычно `http://127.0.0.1:5173/`. Пока приложение открыто, оставьте окно PowerShell запущенным. В других оболочках вместо `npm.cmd` можно писать `npm`.

Сборка создаётся командой `npm.cmd run build`. Для проверки сборки запустите `npm.cmd run preview`.

## Как работает приложение

Компоненты используют Composition API и `<script setup>`. В `usePosts` состояние хранится в `ref`, а загрузка данных начинается в `onMounted`. При размонтировании незавершённая загрузка отменяется через `AbortController`. В странице `computed` рассчитывает отфильтрованные посты и текущую страницу. Поля формы связаны с состоянием через `v-model`.

| Запрос | Действие |
| --- | --- |
| `GET /posts` | Загрузить посты |
| `GET /users` | Загрузить авторов |
| `POST /posts` | Отправить заголовок, текст и ID автора |
| `DELETE /posts/{id}` | Удалить запись из ленты после ответа API |

У всех новых постов один и тот же серверный ID `101`. Поэтому ключи списка генерируются локально, и удаление одной записи не влияет на другую с тем же ID. При ошибке публикации черновик сохраняется. При ошибке удаления карточка остаётся в списке.
